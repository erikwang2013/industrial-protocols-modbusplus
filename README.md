# Modbus Plus 协议包 — 需 Schneider Modbus Plus SA85/BM85 桥接

> [English](README.en.md)

Modbus Plus (MB+) 施耐德电气令牌环网络协议。需要 Schneider SA85/BM85 接口模块，通过内核 Bridge 层桥接。

## 安装

```bash
composer require erikwang2013/industrial-protocols-modbusplus
```

## 功能

Modbus Plus 桥接、BridgeConnector 连接管理

## 所需硬件

Schneider Modbus Plus SA85 接口卡、BM85 桥接模块

## 兼容框架

Laravel / Webman / Hyperf / ThinkPHP / Yii2 / Plain PHP

## 系统要求

- PHP >= 8.1
- Modbus Plus 接口硬件
- erikwang2013/industrial-protocols-kernel
